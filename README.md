# Niko bot

Полноценный телеграм бот, начатый в 2021г и полностью законченный в марте 2022.

Кодовая база проекта была отрефакторена с помощью нейронок.
Из-за чего комментарии местами могут выглядеть немного странно, но куда лучше, чем было написано руками.

# Запуск

Для запуска нужно:
  * Установленный Docker
  * Token вашего бота в файле `.env.dev`

1. Создайте файл `.env.dev` с содержимым по примеру `.env.example`.
2. Загрузите сабмодули:
```bash
git submodule update --init --remote --merge --recursive
```
3. Соберите Docker Image:
```bash
./bin/build-dev
```
4. Запустите инстанс:
```bash
./bin/start-dev
```
